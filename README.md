# CV Studio ✨

A premium, professional CV generator built with Vanilla JavaScript and CSS. Create a stunning resume in minutes with a real-time preview and export it to a high-quality PDF.

![Preview Placeholder](https://img.shields.io/badge/Status-Beta-brightgreen)
![License](https://img.shields.io/badge/License-MIT-blue)

## 🚀 Features

- **✨ Premium UI**: Clean, glassmorphic design system using modern typography.
- **🖼️ Photo Support**: Easily upload your profile photo to your CV.
- **⚡ Real-time Editing**: See changes instantly as you type in the sidebar.
- **💾 Auto-Save**: Your progress is saved to your browser's local storage automatically.
- **📄 PDF Export**: Perfected print styles to ensure your CV looks professional on paper or as a PDF.
- **🔧 Dynamic Sections**: Add or remove as many Work Experience and Education entries as you need.

## 🛠 Tech Stack

- **HTML5**: Semantic and accessible document structure.
- **CSS3**: Advanced styling with Flexbox, Grid, and Glassmorphism.
- **JavaScript (ES6+)**: Pure, framework-less reactivity and file handling.
- **Google Fonts**: [Outfit](https://fonts.google.com/specimen/Outfit) and [Inter](https://fonts.google.com/specimen/Inter).

## 📥 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/yourusername/CV-Studio.git
cd CV-Studio
```

### 2. Run the application
Simply open `index.html` in your favorite web browser!

**Or using npm (optional):**
```bash
npm install
npm start
```
